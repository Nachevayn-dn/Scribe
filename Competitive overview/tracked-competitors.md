## How to update this list

1. Re-run the [ranking criteria](./competitive-landscape.md#proposed-ranking-criteria)
   scorecard for each row where new data exists.
2. Add a row for any new entrant found via KLAS reports, funding trackers
   (Sacra, Latka, PitchBook, Crunchbase), or "best AI scribe" roundup
   articles — these tend to surface new names before press coverage does.
3. Fill in the "Website builder" column once someone has real browser
   access (Wappalyzer extension or a BuiltWith/Wappalyzer API key) —
   this session's sandboxed network egress could not fetch any of these
   sites directly to check.
4. Flag anything marked "New" as reviewed once it has a full profile in
   `competitive-landscape.md`.
